# 🧩 LeetCode Solutions Repository

Automated repository containing solutions to LeetCode problems.

## 📊 Status
- **Total Problems Solved:** 378+

## 🚀 How Solutions Are Synced
This repository uses automated workflows to sync accepted solutions directly from LeetCode.

### Automated Sync Setup
1. `.github/workflows/leetcode-sync.yml` runs daily via GitHub Actions.
2. `export_leetcode.py` can be executed locally to bulk fetch all past submissions.
